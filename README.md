# ♟️ Chess with AI

A pure Python chess game featuring an AI opponent powered by the **Minimax algorithm with Alpha-Beta Pruning**.

## Features

* ♟️ Human vs AI gameplay
* 🧠 Minimax algorithm
* ⚡ Alpha-Beta Pruning
* ♔ Legal move validation
* ♚ Check and Checkmate detection
* ♜ Castling
* ♙ Pawn promotion
* 🖥️ Terminal-based interface
* 🚫 No external Python libraries

## Technologies

* Python
* Minimax
* Alpha-Beta Pruning
* Game Theory
* Recursion

## How to Run

Make sure Python is installed.

```bash
python main.py
```

Then enter moves using chess notation:

```text
e2e4
e7e5
g1f3
```

For pawn promotion:

```text
e7e8q
```

## AI

The computer player evaluates possible game states using **Minimax** and uses **Alpha-Beta Pruning** to reduce unnecessary calculations and improve search efficiency.

## Project Goal

This project demonstrates how fundamental Artificial Intelligence and algorithmic concepts can be applied to create a playable chess game using only Python's standard library.
